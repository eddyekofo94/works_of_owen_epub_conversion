# Foreign Quote Notes Interview

## Goal

Design the replacement foreign-quote popup feature: modernize archaic source references in footnote/popup notes, add translations only when Owen does not already translate the foreign-language passage, attach one clean popup at the complete quote/citation boundary, and avoid inline body translations, bracketed body text, fragment markers, clutter, and false positives.

## Decisions

- The feature must not translate individual words inside a foreign-language quote.
- The feature is not `inline_translations`; it must render reader-facing footnote/popup notes only.
- The main body text must remain unpolluted: no bracketed translations and no dense scattered markers.
- Original Owen/Goold/source footnotes must keep their existing Arabic-number markers untouched.
- Modern editorial reference/translation notes must be visually distinct from original source footnotes and use separate non-Arabic symbols.
- The current project symbol split is acceptable in principle: `†` for modern foreign-language translation notes and `◇` for modern reference/citation notes, while original source footnotes remain Arabic numerals.
- Owen's own translations suppress modern translation notes for the corresponding quote/passages.
- When Owen already provides a translation, a modernized source-reference popup is still desired if the source can be responsibly identified.
- Source/citation information belongs in the same clean popup as the translation when available, or as a citation-only popup only where the user-facing value is high and the anchor can be placed correctly.
- Eligible translation popups include explicit foreign-language quotations and substantial standalone foreign-language clauses/passages.
- Tiny word-level foreign-language runs are not eligible for translation popups.
- Translation popup markers must be anchored after the full foreign-language quote/passage and after its trailing source citation when a trailing citation belongs to that quote.
- Citation-only popup markers may attach to a source citation only when no translation note is needed for the nearby foreign-language quote/passage.
- When Owen provides a nearby English translation or meaningful paraphrase, the system should not duplicate it with a full modern translation note.
- For Owen-translated or Owen-paraphrased foreign-language passages, citation/source-only notes may remain when they add real value and can be anchored after the complete quote/citation unit.
- Modern source references must be high-confidence only: author, work, and location must be identified from Owen's citation or a curated exact mapping.
- If the source is uncertain, the popup should provide the translation only and omit speculative source claims.
- The current phrase/key-driven body translation and citation insertion must be disabled for user-facing output.
- Existing translation/citation databases may be retained as research material, but they should not create fragment-level markers in the rendered body.
- Replacement work should be a quote-level engine that creates at most one note per eligible foreign-language quote/passage.
- Example target behavior: for `Epist. 66 ad Pammach., cap. 10.` after a Latin passage Owen translates, add a citation-only popup with a modernized Jerome reference, but do not add a duplicate translation.
- The Beeke EPUB at `/Users/eddyekofo/Documents/Theology/epub_conversion/books/Beeke/v1/output/v1-epub3.epub` is an example of modern reference wording and scholarly completeness, not a model for changing Owen's existing footnote mechanics.
- Owen should keep this project's current note architecture, generated EPUB structure, styling, and popup behavior unless a separate project-specific defect requires changing it.
- Beeke-style reference wording: footnotes modernize author, work title, internal location, and standard edition location, e.g. `Augustine, On the Trinity, 15.13.22, in NPNF1, 3:212` or `Ignatius, Epistle to the Smyrnaens, chap. 8, in ANF, 1:90`.
- Owen popups should follow this modern-reference style even when the marker was generated by the modern reference engine rather than present in the original source.
- Patristic references should prefer standard English series when available: ANF, NPNF1, NPNF2, Fathers of the Church (FC), Ancient Christian Writers (ACW), Popular Patristics, etc.; add PL/PG column references when available and high-confidence.
- Modern reference enrichment should include page/volume locations when they can be found confidently; if page-level data is unavailable, author + modern work title + book/chapter/section/homily/letter is acceptable.
- Scholastic references should use stable internal divisions first: Aquinas by work + part + question + article + response/objection/ad reply where present; Summa contra Gentiles by book/chapter; Sentences commentaries by book/distinction/question/article; Peter Lombard by Sentences book/distinction/chapter; later Reformed scholastics by locus/topic/question/thesis/section plus modern edition volume/page when available.
- Existing legacy/source footnotes that contain Greek, Latin, or Hebrew should also be enriched: add a clearly indicated modern editorial translation and/or modern reference underneath the original footnote content, formatted consistently with the rest of the project.
- Enriched legacy/source footnotes use the hybrid rule: if the foreign-language material or archaic reference is inside an existing Arabic-numbered footnote, keep the Arabic marker as the only body marker and add the modern editorial reference/translation underneath the original footnote content; if the foreign-language material or archaic reference is in the main body, use the distinct generated symbol note (`†` or `◇`).

## Open Questions

- Decide whether modernized source-reference popups should attach to every high-confidence archaic reference, or only to references attached to foreign-language quote/passages.
